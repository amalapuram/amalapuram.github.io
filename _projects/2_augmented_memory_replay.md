Replay-based continual learning methods store a small buffer of past examples to prevent forgetting, but buffer capacity is limited. {% cite NEURIPS2023_3755a02b %}, published at **NeurIPS 2023**, proposes augmented memory replay strategies that get more out of a fixed memory budget for continual network intrusion detection.
